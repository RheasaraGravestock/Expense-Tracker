# Python Expense Tracking & Data Export Tool

A beginner Python project that tracks expenses, calculates totals, and saves data to a CSV file.

## Features

* Add multiple expenses
* Store expenses using dictionaries and lists
* Calculate total spending
* Validate user input
* Save expenses to a CSV file
* Display all entered expenses

## Technologies Used

* Python
* CSV module

## Concepts Practised

* Functions
* Loops
* Dictionaries
* Lists
* Input validation
* File handling
* CSV export
* Debugging
* Data aggregation basics

## Example Usage

Enter category: Food
Enter amount: 12.50
Enter description: Lunch

Enter category: Travel
Enter amount: 5.20
Enter description: Bus ticket

Output:

ALL EXPENSES

Category: Food
Amount: 12.5
Description: Lunch

Category: Travel
Amount: 5.2
Description: Bus ticket

Total spent: 17.7

## CSV Output Example

Category,Amount,Description
Food,12.5,Lunch
Travel,5.2,Bus ticket
